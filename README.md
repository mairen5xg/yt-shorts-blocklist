# YouTube Shorts Blocklist

A list of uBlock Origin filters that block YouTube Shorts, EXCEPT on any channel's page.
I created it using vibe-coding based on Brave's block list; I wanted one that did the same thing but allowed Shorts on channel pages. If you want one that does the same thing, you can use this one via the following link:

https://raw.githubusercontent.com/mairen5xg/yt-shorts-blocklist/refs/heads/main/yt-shorts-blocklist.txt
